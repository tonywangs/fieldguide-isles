# Asset provenance

All eight SVG files in `assets/` were authored as local vector drawings for Fieldguide Isles on 2026-10-05. They are original project artwork, not downloaded images, generated raster images, or adaptations of third-party sprites. The SVG source is the editable artwork; no separate build pipeline is required.

| File | Subject |
| --- | --- |
| `spriglet.svg` | Leaf-eared seed courier |
| `cindermoth.svg` | Four-winged lantern moth |
| `pebblefin.svg` | Tide-pool fish with pebble and bubbles |
| `fernwhorl.svg` | Fern-shelled spiral crawler |
| `kilnkit.svg` | Clay fox with three warm tails |
| `bellray.svg` | Floating ray with a bell antenna |
| `island.svg` | Island terrain, vegetation, shore and compass; paths and location markers are added by the interface |
| `lighthouse.svg` | Lit lighthouse and neighboring beacons for the ending |

There are no external fonts, icon packages, textures, tracking pixels, CDNs, remote scripts, audio, or runtime libraries. The interface uses local system fonts and ordinary text symbols. Species names, descriptions, story, and map geometry were authored for this project. No third-party game names or characters appear in the game. Development-only Playwright dependencies retain their own upstream licenses in the installed packages. This repository does not grant a license to third-party works mentioned in research references.
